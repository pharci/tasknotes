# TaskNotes Fork - Development Guide

This is a personal Obsidian plugin fork. Its plugin ID is `tasknotes-fork`.

## Build and validation

```bash
npm run build:test
npm test
npm run lint
npm run typecheck
```

`build:test` copies the built plugin to the repository's local test vault.
Set `OBSIDIAN_PLUGIN_PATH` to a vault's
`.obsidian/plugins/tasknotes-fork` folder to use another vault.

The entry point is `src/main.ts`; source styles are in `styles/`. Root
`main.js`, `styles.css`, and `src/releaseNotes.ts` are generated by the build.
Keep locale files under `src/i18n/resources` in their target language. Run
`npm run i18n:sync` after changing translations.

Do not weaken lint rules to make a change pass. Keep changes focused and update
the relevant tests when behavior changes.
